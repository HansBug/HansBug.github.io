## 这批参考图里最值得抽取的关键词

- 深灰和煤灰层次，而不是纯黑。
- 大量窄长矩形面板，而不是圆润卡片。
- 宽体英文工业字承担结构感，中文只保留必要信息。
- 冷青只做主强调，橙色只做局部状态线。
- 背景可以复杂，但 UI 本体必须克制。
